# Dayline 자세한 사용법과 규칙

처음 쓰는 분은 [README](../README.md)부터 보세요. 여기는 기능별 동작과 입력 규칙을 모두 적어 둔 곳이에요.

## 앱에서 동작하는 것

- X를 누르면 트레이로 숨고, 알림은 계속 와요. 완전 종료는 트레이 아이콘 우클릭 → 종료.
- 작은 메모창은 항상 위에 고정돼요(핀 버튼으로 끄고 켜기). 큰 앱과 작은 메모창의 위치·크기를 따로 기억해요.
- 미리 알림은 Windows 알림으로 와요. 알림의 [완료]는 할 일을 완료하고, [확인]은 앱을 열지 않고 알림만 닫아요.
- 어디서든 `Ctrl + Shift + Space`를 누르면 창이 열리고 입력창에 커서가 가요.
- 설정 → 스티커 메모 가져오기에서 Windows 스티커 메모를 바로 읽어와요.
- 설정 → 한 일 내보내기(또는 타임라인 위 내려받기 아이콘): 기간(이번 주·지난주·이번 달·지난달·최근 3개월·전체)을 골라 날짜별 한 일을 Markdown(읽기·AI 정리용)이나 CSV(엑셀용)로 복사하거나 파일로 저장해요. 작업 중·남은 일도 같이 넣을 수 있어요.
- 컴퓨터 켤 때: 설정에서 안 켜기 / 트레이에만 / 창 열기 중에 골라요. 처음 실행할 때 물어보고, 고르기 전에는 꺼져 있어요.
- 하루 한 번 `문서\Dayline 백업` 폴더에 자동 백업하고 최근 30일 치를 남겨요(설정 → 지금 백업 / 폴더 열기).
- 되살리기: 설정 → 백업 가져오기에서 자동 백업 목록이나 백업 파일을 고른 뒤 **이 백업으로 되돌리기**(통째로 바꿈) 또는 **합치기**(없는 할 일만 더함)를 골라요. 되돌리기 전 상태는 `dayline-before-…json`으로 따로 저장되고(최근 5개), 바로 뒤 되돌리기 버튼으로도 취소할 수 있어요.
- 입력창에서 `#`을 치면 프로젝트 목록이 떠요. 글자를 더 쳐서 좁히고 ↑↓·Enter(또는 Tab)로 고르면 입력창 앞에 프로젝트 칩이 붙어요(없는 이름이면 새 프로젝트로 만들기). 칩은 ×나 맨 앞에서 Backspace로 빼요. 칩으로 고른 프로젝트가 단어 자동 연결보다 우선이에요.
- 할 일 문장에 프로젝트 이름이나 첫 단어("모바일앱", "홈페이지")가 있으면 그 프로젝트로 자동으로 들어가요. 프로젝트 편집에서 "자동 연결 단어"를 더 넣을 수 있어요.
- 처음 설치하면 빈 상태로 시작해요(샘플 데이터는 브라우저 데모에만 있어요). 새 버전을 설치해도 데이터는 그대로예요.
- 다른 사람에게 줄 때는 `Dayline Setup x.y.z.exe` 하나만 보내면 돼요. 데이터는 각자 PC에 따로 저장돼요.
- 데이터는 이 PC의 Dayline 앱 폴더에 저장돼요(브라우저 프로토타입의 데이터와는 따로예요. 옮기려면 브라우저 쪽에서 백업 내보내기 → 앱에서 백업 가져오기).

## 브라우저 프로토타입으로 열기

- `index.html`을 Chrome이나 Edge로 열면 돼요. 설치할 건 없어요.
- 진짜 Windows 알림까지 보려면 `run-local.bat`을 실행하세요. Node.js가 있어야 하고, `http://localhost:5173`으로 열려요. 파일로 바로 열면 브라우저가 알림 권한을 막는 경우가 있어서, 그때는 앱 안 알림(오른쪽 아래 카드)만 와요.

## 먼저 해볼 것

1. 입력창에 `2시 디자인 리뷰`를 치고 Enter → 14:00에 들어가고 "미리 알려드릴까요?"가 떠요.
2. `3시-4시 미팅 #홈페이지`, `내일 10:00 회의`, `30분 후 전화`도 쳐 보세요. 치는 동안 입력창 위에 어떻게 읽었는지 보여요.
3. 타임라인은 일·주·월로 볼 수 있어요. 월 보기에서는 날짜 칸마다 마감(깃발), 예정(반복은 회색), 한 일(✓ 완료, ▶ 작업한 일, 제목으로)이 보이고, 날짜 숫자를 누르면 그날을 크게 보고, +N을 누르면 그날 할 일이 팝업으로 펼쳐져요. 마우스 뒤로/앞으로 버튼(또는 Alt+←/→)으로 보던 화면으로 돌아가요. 할 일·마감을 다른 날짜 칸으로 끌면 옮겨져요.
4. 주간 보기에서 요일 사이 경계(날짜 머리 오른쪽 끝)를 좌우로 끌면 그 요일 칸을 넓히거나 좁힐 수 있어요. 경계를 두 번 누르면 원래대로 돌아가요.
5. 타임라인(일·주)의 빈 곳을 마우스로 끌면 그 시간에 할 일을 바로 만들 수 있어요(클릭만 하면 30분). 이미 지난 시간이면 "한 일로 완료"가 켜진 채로 열려요.
6. 위쪽 "타임라인"에서 왼쪽 "시간 미정" 카드를 시간표로 끌어다 놓거나, 블록을 옮기고 아래 끝을 끌어 길이를 바꿔 보세요.
7. "작은 메모창으로"를 누르면 바탕화면 위 작은 창으로 바뀌어요. 위쪽 막대를 잡고 옮길 수 있어요.
8. 할 일을 체크하면 타임라인에 "한 일" 블록으로 남아요.
9. `모바일앱 기획서 검토 목요일까지`처럼 치면 마감이 잡혀요. 목록 왼쪽에 D-3 / 오늘 / 지남이 보이고, 상세에서 마감 날짜·시각을 바꿀 수 있어요. `내일까지`, `10/23까지`, `금요일 6시까지`, `이번 주까지`, `월말까지`, `목요일 마감`도 돼요.
10. 할 일에 마우스를 올리고 ▶를 누르면 작업 시간 기록이 시작돼요. 멈추면 그 시간이 완료 전이라도 타임라인 "한 일"에 초록으로 남아요. 상세의 **작업 시간**에서 기록 줄을 누르면 시작·끝을 직접 고칠 수 있고(하는 중이면 시작만), "+ 직접 넣기"로 이미 한 작업을 넣을 수 있어요. 타임라인에서 끌어 옮기거나 길이를 바꿀 수도 있어요("시간 미정"으로 끌면 그 기록이 지워져요). 계획한 "시간"과는 따로예요.
11. `매주 수요일 9시-10시 주간 회의`처럼 치면 반복 일정이 돼요. `매일`, `평일`, `매주 월,수,금`, `매월 25일`도 돼요. 수정·삭제할 때 "이번 회차만 / 앞으로 전부"를 고를 수 있어요.

## 데모용 주소 옵션

| 주소 뒤에 붙이기 | 하는 일 |
| --- | --- |
| `?reset` | 샘플 데이터로 처음부터 |
| `?t=2026-10-16T13:19:55` | 앱 시계를 그 시각으로 (13:20 알림이 몇 초 뒤 울려요) |
| `?fail=save` | 저장 실패 화면 보기 |

## 브라우저 프로토타입에서는 흉내만 내는 것

- 항상 위에 고정, 트레이 숨기기, Windows 시작 시 실행 → Windows 앱에서만 실제로 동작
- 스티커 메모 가져오기 → 브라우저에서는 붙여넣기 방식
- 데이터는 그 브라우저에만 저장돼요(localStorage). 설정 → 백업 내보내기로 옮길 수 있어요.

## 정한 규칙

- 오전/오후가 없으면 업무시간(9~18시) 기준: 9·10·11시는 오전, 12시는 정오, 1~6시는 오후, 7·8시는 지금 이후 가장 가까운 시각, 날짜 없이 이미 지난 시각은 내일.
- 입력한 문장은 그대로 저장해요. 목록·타임라인 제목에서는 시간·날짜·반복·마감·#프로젝트 문구를 빼고 보여줘요(왼쪽 칸과 아래 줄에 따로 보이니까). 목록에서는 제목 맨 앞의 프로젝트 단어("모바일앱 ...")도 빼요. 막 추가한 직후 잠깐은 어떻게 읽었는지 밑줄로 보여주고, 상세에서도 제목만 보여주고, 제목을 고치지 않으면 원래 문장이 그대로 남아요.
- 처음 실행하면(할 일이 없을 때) 사용법 3가지와 "컴퓨터를 켤 때 Dayline도 켤까요?"를 물어요. 자동 실행은 여기서 켜야 켜져요. 설정 → 도움에서 사용법을 다시 보거나, **의견 보내기**로 문제·개선점을 스크린샷·파일(최대 10개)과 함께 보낼 수 있어요. 버전·Windows 정보만 같이 가고 할 일 내용은 빠져요. 받는 곳은 `tools/feedback-apps-script.gs`(Google Apps Script)를 배포한 뒤 `FEEDBACK_URL`에 넣으면 앱에서 바로 메일로 와요. 비어 있으면 메일 앱이 열려요.
- 할 일 가져오기(설정 → 데이터): 붙여넣은 글·.txt/.md 파일·스티커 메모를 한 줄씩 할 일로 만들어요. 입력칸에 여러 줄을 붙여넣거나 파일을 창에 끌어다 놓아도 열려요. 목록 기호는 떼고, 끝난 줄·제목 줄·비밀번호처럼 보이는 줄은 기본으로 빼요.
- 옆 달력(큰 화면 목록): 위쪽 달력 아이콘으로 켜고 꺼요. 날짜 밑 점은 할 일(프로젝트 색)·마감(주황)·한 일만 있는 날(빈 점)이에요. 날짜를 누르면 아래에 그날 할 일·마감·한 일이 나오고, "이 날 할 일 추가"로 바로 넣을 수 있어요. 두 번 누르면 타임라인 그날로 가고, 목록의 할 일을 날짜 위로 끌어 놓으면 그날로 옮겨져요. 창이 좁으면 숨어요.
- 목록은 작업 중 → 할 일 → 일정 순서예요. 할 일 = 오늘 할 것(시간 없는 일·날짜 없는 일·마감 있는 일이 먼저, 그 아래 오늘 시간 있는 일이 현재 시각 선과 함께) + 날짜가 지난 일, 일정 = 내일 이후 날짜가 잡힌 일(반복 포함, 마감만 있는 일은 마감 날에, 시간 자리에 주황 "⚑ 마감 11:00"과 D-n으로 표시). 그날이 되면 일정이 할 일로 올라와요.
- 내일로 미루기: 할 일을 열면 날짜 옆에 "내일로"(이미 앞날이면 "하루 뒤로") 버튼이 있어요. 날짜 칩의 ×는 날짜 지우기예요. "할 일" 제목 옆 "오늘 남은 N개 내일로"로 한 번에 옮길 수도 있고, 바로 되돌리기도 돼요.
- 작업 기록이 있는 미완료 할 일은 맨 위 "작업 중"에 모여요. 작업 중인 것이 맨 위, 나머지는 최근에 작업한 순서예요.
- 말 구분: **시간**은 계획(언제 하기로 했는지), **작업**은 ▶로 실제로 한 기록이에요. 계획 시간이 됐는데 ▶를 안 눌렀으면 주황 "시작 전"이 붙어요. 오늘 시간이 정해진 일은 마우스를 올리면 오른쪽에 **▶ 시작 · ⏰ 미루기**가 나오고, 시간이 끝나면 빨강 "지남"이 돼요. 미루기는 지금부터 30분·1시간·2시간 뒤(5분 단위로 맞춤) 또는 내일로 옮기고 길이와 알림도 같이 옮겨요. 반복 일정은 이번 회차만 옮겨요.
- 알림은 자동으로 켜지지 않아요. 고르지 않으면 할 일과 시간만 저장돼요.
- "~까지"는 시작 시간이 아니라 마감으로 저장해요. 목록 제목에서는 마감 문구를 숨기고 아래 줄(깃발)에 보여줘요. 원래 문장은 상세에서 그대로 볼 수 있어요. `3시부터 5시까지`처럼 범위의 끝일 때만 종료 시간이에요. 마감 시각에 오전/오후가 없으면 9~12시는 오전, 그 밖은 오후로 읽어요.
- 마감만 있는 할 일의 미리 알림: 시각이 없으면 마감일 아침 업무 시작(9시) 기준(당일 아침 / 하루 전 / 이틀 전), 시각이 있으면 그 시각 기준이에요.
- 반복 일정은 회차마다 따로 완료돼요. 타임라인에서 회차를 끌어 옮기면 그 회차만 바뀌어요.
- 타임라인의 "한 일" 블록 = 시작 시간 ~ 완료를 누른 시각. 직접 넣은 종료·소요 시간이 있으면 그 값을 써요.

## 파일

- `index.html` – 진입점
- `styles.css` – 디자인(색·글꼴·간격)
- `js/parser.js` – 문장 속 시간 인식
- `js/app.js` – 화면, 할 일, 알림, 타임라인, 드래그
- `electron/main.js` – 창, 트레이, Windows 알림, 자동 실행, 스티커 메모 읽기
- `electron/preload.js` – 화면이 쓸 수 있는 앱 기능 목록
- `assets/` – 아이콘, 내장 글꼴(Pretendard, OFL)
- `build/` – 설치 파일용 아이콘, exe 아이콘·이름 넣는 스크립트
